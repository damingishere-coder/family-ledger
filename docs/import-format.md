# 历史数据导入格式

选择文件后，FamilyLedger 会先进行只读解析并显示日期、有效行数和警告。此时不会写入数据库；只有点击“确认导入”才会创建成员、账户、快照和导入记录。

## CSV / Excel

支持 `.csv`、`.xlsx` 和 `.xlsm`，不支持旧版 `.xls`。CSV 可以使用 UTF-8（含 BOM）或中文 Windows 常见的 GB18030 编码；单个文件不能超过 20MB。

CSV 与 Excel 的第一行必须是表头。列名支持中文或英文，最小示例：

| 盘点日期 | 家庭成员 | 账户名称 | 账户类型 | 金额 |
|---|---|---|---|---:|
| 2026-08-31 | 大明 | 微信 | wallet | 987.63 |
| 2026-08-31 | 大明 | 招商银行信用卡 | credit_card | -18.52 |

可选列：机构名称、信用额度、是否计入家庭净资产。

账户类型必须使用以下稳定值之一；中文描述仍可作为辅助文字，但建议使用英文枚举：

- `wallet`
- `debit_card`
- `credit_card`
- `investment`
- `receivable`
- `other_asset`
- `other_liability`

空白金额会导入为 `NULL`，不会变成零。疑似重复名称会形成警告，不会自动合并。

## Markdown

支持 `.md`、`.markdown` 和 `.txt`，文本编码可以是 UTF-8（含 BOM）或 GB18030。日期标题需包含类似 `## 2025年12月25日` 的内容，并在成员“明细”标题下列出账户和金额。

无法识别的文件、损坏的工作簿和完全没有有效明细的内容会停留在预览窗口并显示原因，不会静默写入部分空数据。
